# Polaris Maritime Consulting — sito gratuito

Questa è una prima versione statica del sito aziendale, costruita in HTML/CSS/JavaScript e basata sul logo fornito.

## Struttura
- `index.html` — pagina principale
- `styles.css` — grafica responsive
- `script.js` — menu mobile e interazioni
- `logo.jpg` — logo fornito

## Pubblicazione gratuita
Il sito può essere pubblicato gratuitamente con servizi di hosting statico come GitHub Pages.
Il dominio `polarismaritime.it` può essere collegato in seguito, se il dominio viene registrato.

## Da personalizzare
Prima della pubblicazione definitiva conviene sostituire i testi generici con:
- descrizione reale dell'azienda
- elenco effettivo dei servizi
- telefono
- email
- indirizzo completo
- eventuali foto, flotta e progetti
- Privacy/Cookie Policy
